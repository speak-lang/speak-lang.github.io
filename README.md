# Speak website

Source of <https://speak-lang.github.io/>, the home page of [Speak](https://github.com/speak-lang/speak), a programming language for learning to code in your native tongue.

It is plain static files with no build step and no scripts: `index.html`, `404.html` and `style.css`. GitHub Pages serves the repository root from `main`.

To preview locally:

```sh
python3 -m http.server 8000
```

The playground lives in [speak-lang/speak-playground](https://github.com/speak-lang/speak-playground).

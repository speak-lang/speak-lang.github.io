Learn to code in the language you think in.

Speak is an open-source programming language where the keywords, built-in functions and error messages come from translation files. The same program can be written in English or Swahili today, and in more languages as native speakers add them.

Try it in the playground

The same program, two languages

A FizzBuzz function, written in English and in Swahili. Both run on the current interpreter.

English

// speak fizzbuzz implementation
fizzbuzz: n number -> string
    if n % 15 = 0 ? "FizzBuzz"
    if n % 3 = 0 ? "Fizz"
    if n % 5 = 0 ? "Buzz"
    sprint n

// call with 45
print "fizzbuzz result for {} is {}" 45 (fizzbuzz 45)

Kiswahili

fizzbuzz: n nambari -> mlolongo
    kama n % 15 = 0 ? "FizzBuzz"
    kama n % 3 = 0 ? "Fizz"
    kama n % 5 = 0 ? "Buzz"
    mlolongo_andika n

// ita na nambari 45
andika "matokeo ya fizzbuzz kwa {} ni {} yenyewe" 45 (fizzbuzz 45)

Why Speak

  • Learn in your mother tongue. Most programming tools assume English. In Speak, the words in your code are words you already know.
  • Built for classrooms. Designed with teachers and learners, first in Kenya, with lessons that ship alongside the interpreter.
  • Works offline. No internet needed once it is installed, which matters in schools with little or no connectivity.
  • Runs on modest hardware. Small enough for a Raspberry Pi.
  • Runs in the browser. The interpreter also compiles to WebAssembly, so it works in the playground with nothing to install.

Help without writing Rust

You do not need to be a programmer to help.

  • Translate. Native speakers of Dholuo, Gĩkũyũ and other languages can add a locale file so learners can code in their language.
  • Teach. Try Speak with a class or a study group and tell us what worked and what confused people.
  • Test. Run the samples, try to break them, and report what you find.

Start with the contributing guide. Everyone taking part follows the code of conduct.
